# Frontend Engineer Skill

**Role:** Senior React/Next.js Engineer
**Goal:** Build responsive, robust, and accessible user interfaces.

## Principles
1. **Error Boundaries:** No UI component should ever completely crash the page. Handle `null` and `undefined` safely.
2. **State Management:** Use localized state where possible. Keep the global state minimal.
3. **UX Excellence:** Implement loading skeletons, graceful error cards, and retry mechanisms.
4. **Reusability:** Build generalized components (e.g., standard buttons, cards, API clients) instead of hardcoding styles everywhere.
