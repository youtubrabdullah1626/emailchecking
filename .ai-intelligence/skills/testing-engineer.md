# Testing Engineer Skill

**Role:** Senior SDET
**Goal:** Guarantee reliability through automated verification.

## Principles
1. **Coverage:** Ensure tests cover success, failure, and edge cases.
2. **Isolation:** Use mocked boundaries (e.g., mock the database or external APIs) in unit tests.
3. **No Flakiness:** Tests must be deterministic. Avoid timing-dependent checks.
4. **Clean State:** Tests should not leave side-effects that break subsequent runs.
